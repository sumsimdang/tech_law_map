# 기술보호법 인용 지도

**공개 주소: https://sumsimdang.github.io/tech_law_map/**

기술보호 관련 17개 법률(산업기술보호법, 국가첨단전략산업법, 방산기술보호법, 부정경쟁방지법, 중소기업기술보호법 등)에 대해 아래 내용을 원문 구절과 함께 보여 주는 페이지예요. 누구나 로그인 없이 휴대폰이나 PC 브라우저로 볼 수 있어요.

- **법률 관계**: 법률끼리 주고받은 인용 (지도 · 행렬)
- **조문 인용**: 한 조문을 중심으로 본 인용망, 전체 조문 지도. 법률 조문마다 그 조문을 구체화한 시행령 조문도 함께 보여요.
- **기술 개념**: 국가핵심기술, 국가첨단전략기술, 영업비밀, 방산기술 같은 개념의 정의·포함관계·시행령 세부 사항, 그리고 국가핵심기술·국가첨단전략기술·방위산업기술·전략물자 네 지정의 고시 목록과 두 가지씩 여섯 쌍의 비교
- **유출 처벌**: 법률마다 '유출'을 무엇으로 정의하고 형량이 얼마인지 비교

## 매주 자동 갱신

매주 월요일 오전 6시 무렵(한국 시간)에 GitHub Actions가 아래 순서로 페이지를 다시 만들어요.

1. [legalize-kr](https://github.com/legalize-kr/legalize-kr) 저장소에서 최신 법률·시행령 원문을 받아요.
2. 조문 인용을 다시 뽑고, 오늘 시행 중인 판본과 시행 예정 개정을 가려내요.
3. 개념·유출 비교에 쓴 근거 구절이 원문에 그대로 있는지 하나씩 대조해요.
4. 대조를 통과하면 같은 주소에 새로 게시하고, 바뀐 내용을 `changelog.json`에 남겨요. 페이지의 '자료 안내'에서도 이 기록을 볼 수 있어요.

### 갱신이 멈출 때

근거 구절이 원문과 맞지 않으면 게시하지 않고 **Issues에 '확인 필요' 글**을 올려요. 대개 개정이 시행돼 문구가 바뀐 경우예요. 그동안 공개 페이지는 지난 판 그대로 남아요.

고치는 방법은 이래요. 이슈 내용을 Claude에게 보여 주고 `topics.py`를 고쳐 달라고 하면 돼요. 고친 파일을 올리면 바로 다시 만들어지고, 이슈는 자동으로 닫혀요.

지금 알고 있는 멈춤 예정 시점은 두 번이에요.

- 2026-12-10 방산기술보호법 제21조 개정 시행 → 12월 14일 점검에서 멈춤
- 2027-03-16 부정경쟁방지법 제18조 개정 시행 → 3월 22일 점검에서 멈춤

### 바로 다시 만들기

Actions 탭 → **주간 법령 점검** → **Run workflow**를 누르면 돼요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `run_update.py` | 주간 점검 전체 순서 |
| `parse.py` | 법률·시행령 조문과 인용 추출 |
| `versions.py` | 시행 중 판본과 시행 예정 개정 구분 |
| `topics.py` | 개념·유출 비교 데이터와 근거 구절 검증 |
| `build.py`, `template.html` | 페이지 조립 |
| `page.py` | 문서 뼈대와 링크 미리보기 태그 |
| `notify.py` | 갱신이 멈췄을 때 Issues에 올릴 글 작성 |
| `diagA.json`, `diagB.json` | 개념 포함관계 도식의 도형 배치 |
| `techlist.json` | 국가핵심기술·국가첨단전략기술·방위산업기술·전략물자 고시 목록과 여섯 쌍 비교 (고시가 바뀌면 손으로 고침) |
| `state.json`, `changelog.json` | 지난 점검 상태와 기록 (자동 갱신) |
| `og.png` | 카카오톡 같은 메신저의 링크 미리보기 이미지 |
| `.github/workflows/weekly.yml` | 주간 실행과 Pages 게시 |

법률 간 인용표는 CSV로도 받을 수 있어요: https://sumsimdang.github.io/tech_law_map/cross_citations.csv

## 고시 목록은 손으로 관리해요

`techlist.json`의 고시 문구는 법제처 국가법령정보 공동활용 서비스의 현행 행정규칙 원문에서 옮겼어요. 고시는 legalize-kr 저장소에 없어서 주간 자동 점검으로 대조하지 못해요. 지금 기준은 국가핵심기술 고시 산업통상부고시 제2025-002호(2025-10-02), 국가첨단전략기술 고시 제2025-71호(2025-05-18 시행), 방위산업기술 지정 고시 방위사업청고시 제2023-3호(2023-06-15), 전략물자수출입고시 산업통상부고시 제2026-101호(2026-09-01 시행)예요. 고시가 개정되면 이 파일을 고쳐 올려야 해요.

## 주의

이 페이지는 법률 자문이 아니에요. '조문 해석'으로 표시한 포함관계는 조문 문언에서 끌어낸 정리예요. 실무에서는 판례와 유권해석을 함께 확인하세요.
